检查推送源状态中…

第 1 步 · 安装证书（每部推送手机仅需一次）

  1. iPhone 相机扫描左侧二维码
  2. Safari 会下载描述文件 → 点"允许"
  3. 设置 → 通用 → VPN与设备管理 → 安装（输锁屏密码）
  4. 设置 → 通用 → 关于本机 → 证书信任设置 → 打开 baby-monitor-local-ca 完全信任

第 2 步 · 打开推流页开始推流（每次监控时）

  1. iPhone 相机扫描左侧二维码，打开推流页
  2. 点"▶ 开始推流" → 允许摄像头/麦克风权限
  3. 看到"🟢 推流中"即成功
  4. 固定好手机、接电源、保持页面常开（页面会自动保持屏幕常亮）
💡 换了电脑的局域网 IP 后，需在电脑上重新运行 bash tools/make_certs.sh <新IP> 并重启服务，手机无需重新安装证书。
