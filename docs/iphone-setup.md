# iPhone 推流配置（浏览器，无需安装 App）

推流通过一个网页完成：iPhone 用 Safari 打开推流页 → 授权摄像头 → 一键推流。
要求 **屏幕常亮**（已内置 Wake Lock，另建议系统"自动锁定"设为"永不"）并保持页面在前台。

## 最简方式：扫码注册（推荐）

任何一部家里的手机打开 `http://<电脑IP>:8080/sources`（输入访问口令），页面上有两个二维码：

1. **第 1 步·安装证书**：iPhone 相机扫码 → 安装描述文件 → 证书信任设置开完全信任（仅需一次）
2. **第 2 步·打开推流页**：iPhone 相机扫码 → 点"开始推流"

页面顶部还会实时显示当前是否有推送源在线。

## 手动方式（与扫码等效）

### 首次准备（一次性，约 3 分钟）

iOS 只允许 HTTPS 页面使用摄像头，因此需要安装我们自己的本地证书：

1. 电脑端已生成证书（`tools/make_certs.sh <电脑IP>`），iPhone 与电脑连同一 Wi-Fi
2. iPhone Safari 打开 `http://<电脑IP>:8080/ca.crt`
   - 弹出"网站正尝试下载一个配置描述文件"→ 允许
   - 设置 → 通用 → VPN与设备管理 → 已下载的描述文件 → 安装（输入锁屏密码）
3. 设置 → 通用 → 关于本机 → **证书信任设置** → 打开 `baby-monitor-local-ca` 的完全信任开关
   （第 3 步不做，推流页会提示证书错误）

> 换了电脑的局域网 IP 时需重新生成证书：`bash tools/make_certs.sh <新IP>` 并重启服务，手机无需重新安装。

## 1. 日常使用（每次监控时）

1. iPhone Safari 打开 `https://<电脑IP>:8443/push`（首次如出现证书警告，
   可点"高级 → 仍要访问"进入；安装并完全信任证书后警告消失）
2. 点"▶ 开始推流"，首次会请求摄像头/麦克风权限 → 允许
3. 看到"🟢 推流中"即成功；画面预览在页面上方
4. 摆好手机位置（"🔄 翻转"可切换前后摄像头），接电源，保持页面常开

> 推流连接由服务端同源代理转发，手机只需要访问后端自身（8080/8443），
> 不存在其他端口的证书问题。

## 2. 长时间稳定要点

- iOS 设置 → 显示与亮度 → 自动锁定 → **永不**（页面的 Wake Lock 已保持常亮，这是双保险）
- 常接电源；可开启低电量模式降低发热
- 开启 iOS"专注模式"避免来电/通知打断（来电会中断推流，恢复后页面会自动重连）
- Safari 打开其他页面或切后台超过一段时间会暂停采集 → 保持本页在前台

## 3. 验证

在另一部手机浏览器打开 `http://<电脑IP>:8080`（口令见 config.yaml），能看到画面即成功。

## 常见问题

- **"❌ 无法获取摄像头"**：确认地址栏是 `https://`（不是 http）；若曾拒绝过授权，
  到 iOS 设置 → Safari → 相机/麦克风 改为"允许"
- **推流页证书警告**：可点"仍要访问"直接使用；按"首次准备"安装证书后警告消失
- **"❌ 连不上电脑端服务"**：确认电脑端 MediaMTX + 监控服务已启动，防火墙已放行端口
- **中途画面断了**：页面会自动重连；若长时间未恢复，回到推流页重新点开始
